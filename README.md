# Drowsiness Detection

ระบบตรวจจับอาการง่วงของผู้ขับขี่แบบเรียลไทม์ด้วยเทคนิคการมองเห็นด้วยคอมพิวเตอร์ (Computer Vision) และโมเดล CNN

## ภาพรวมโครงการ

โปรเจกต์นี้พัฒนาระบบตรวจจับอาการง่วงหรือหลับในของผู้ขับขี่ โดยอ่านสัญญาณจากใบหน้าผ่านกล้องเว็บแคม ได้แก่ การหลับตานาน การกะพริบตา และการหาว แล้วแจ้งเตือนด้วยเสียงเพื่อเพิ่มความปลอดภัยในการขับขี่

ระบบแก้ข้อจำกัดของวิธีเดิมที่ใช้ค่า EAR ตายตัว ซึ่งไม่เหมาะกับผู้ที่มีตาเล็ก และคลาดเคลื่อนง่ายเมื่อมีแสงสะท้อนจากแว่นหรือแสงเปลี่ยนไป โดยใช้การสอบเทียบเกณฑ์เฉพาะบุคคลร่วมกับโมเดล CNN ที่ช่วยยืนยันสภาพตาจากภาพจริง

## วัตถุประสงค์

- ตรวจจับสัญญาณของความง่วงนอนแบบเรียลไทม์ (หลับตานาน, หาว, กะพริบตา)
- ปรับเกณฑ์การตรวจจับให้เหมาะกับดวงตาของผู้ใช้แต่ละคนโดยอัตโนมัติ
- ลดการเตือนผิดพลาดจากตาเล็ก แสงสะท้อนแว่น และแสงที่เปลี่ยนไป
- แจ้งเตือน 2 ระดับตามความรุนแรง เพื่อไม่ให้รบกวนผู้ขับโดยไม่จำเป็น
- บันทึกเหตุการณ์ลงไฟล์ CSV เพื่อนำไปวิเคราะห์ย้อนหลัง

- **MediaPipe Face Landmarker** ตรวจจับใบหน้าและจุดสำคัญ (landmarks)
- **TensorFlow / Keras** สร้างและเรียกใช้โมเดล CNN จำแนกตาเปิด/ปิด
- **NumPy, SciPy** คำนวณเชิงตัวเลขและระยะห่างระหว่างจุด
- **scikit-learn** แบ่งข้อมูลและประเมินผลโมเดล
- **pygame** สร้างเสียงเตือน
- **Jupyter Notebook** เทรนและประเมินโมเดล

## การทำงาน

### ขั้นตอนการประมวลผล

1. **การจับภาพ (Capture)** รับภาพจากเว็บแคมทีละเฟรม
2. **การตรวจจับใบหน้า (Face Landmark)** ใช้ MediaPipe Face Landmarker หาจุดสำคัญรอบตาและปาก
3. **การคำนวณ (Feature)** คำนวณ EAR (ตา) และ MAR (ปาก)
4. **การสอบเทียบ (Calibration)** 3 วินาทีแรก วัด EAR ขณะลืมตาปกติ เพื่อกำหนดเกณฑ์เฉพาะบุคคล
5. **การตัดสินใจ (Decision)** ถ้า EAR ต่ำกว่าเกณฑ์ ให้ CNN ตรวจภาพตาเพื่อยืนยันว่าตาปิดจริง
6. **การแจ้งเตือน (Alert)** จับเวลาที่ตาปิดต่อเนื่องและแจ้งเตือนตามระดับ

### เกณฑ์การแจ้งเตือน

| เหตุการณ์ | เงื่อนไข | ผลลัพธ์ |
|---|---|---|
| กะพริบตา | ตาปิด 0.05–1.0 วินาที | นับเป็นการกะพริบ |
| หลับตานาน | ตาปิดต่อเนื่อง ≥ 5 วินาที | เตือนเสียงเบา (660 Hz) |
| หลับตานานมาก | ตาปิดต่อเนื่อง ≥ 10 วินาที | เตือนเสียงดัง (1500 Hz) |
| หาว | MAR > 0.60 ต่อเนื่อง ≥ 3 วินาที | เตือนเสียงเบา |

### เมตริกการตรวจจับ

- **EAR (Eye Aspect Ratio):** สัดส่วนความสูงต่อความกว้างของตา ใช้บอกว่าตาหรี่หรือปิด
- **MAR (Mouth Aspect Ratio):** สัดส่วนการเปิดของปาก ใช้ตรวจจับการหาว
- **CNN Eye State:** ความน่าจะเป็นที่ตาเปิด (ค่า < 0.5 คือโมเดลเห็นว่าตาปิด)
- **Blink Count:** จำนวนการกะพริบ ทั้งสะสมและต่อนาที
- **Facial Landmarks:** จุดสำคัญบนใบหน้า (ตา 6 จุดต่อข้าง, ปาก 8 จุด)

### โมเดล CNN

- **Input:** ภาพตาขาวดำ 64×64 (ผ่าน `equalizeHist` เพื่อลดผลของแสงสะท้อนและความสว่าง)
- **โครงสร้าง:** Conv2D 3 ชั้น (32, 64, 128 filters) พร้อม BatchNormalization และ MaxPooling → Flatten → Dropout 0.4 → Dense 64 → Dense 1 (Sigmoid)
- **Data Augmentation:** RandomFlip (แนวนอน), RandomRotation (0.05), RandomZoom (0.1)
- **พารามิเตอร์:** 388,609 ตัว (1.48 MB)
- **การเทรน:** Adam, Binary Crossentropy, สูงสุด 30 epochs, batch size 32, EarlyStopping (patience 5) และ ReduceLROnPlateau (factor 0.5, patience 2)

## โครงสร้างโปรเจกต์

```
Drowsiness-detection/
├── README.md
├── main.py                       # โปรแกรมตรวจจับแบบเรียลไทม์
├── Drowsiness-detection.ipynb    # Notebook เทรนและประเมินโมเดล CNN
├── eye_state_cnn.h5              # โมเดลที่เทรนแล้ว (สร้างจาก notebook)
├── face_landmarker.task          # โมเดล MediaPipe (ดาวน์โหลดอัตโนมัติครั้งแรก)
├── dataset/
│   ├── open/                     # ภาพตาเปิด (2,000 ภาพ)
│   └── closed/                   # ภาพตาปิด (2,000 ภาพ)
└── data-user/                    # ไฟล์ log CSV ของแต่ละรอบการใช้งาน (สร้างอัตโนมัติ)
```

## วิธีการใช้งาน

1. **ติดตั้ง Dependencies**

   ```bash
   pip install opencv-python mediapipe numpy scipy pygame tensorflow scikit-learn
   ```

2. **เตรียม Dataset** (เฉพาะกรณีต้องการเทรนโมเดลใหม่)

   วางภาพตาเปิดไว้ใน `dataset/open` และตาปิดไว้ใน `dataset/closed` ชุดข้อมูลที่ใช้: [Drowsiness Detection Dataset (Kaggle)](https://www.kaggle.com/datasets/prasadvpatil/mrl-dataset) ซึ่งอ้างอิงจาก MRL Eye Dataset

3. **เทรนโมเดล** (ข้ามได้ถ้ามีไฟล์ `eye_state_cnn.h5` อยู่แล้ว)

   ```bash
   jupyter notebook
   ```

   เปิด `Drowsiness-detection.ipynb` แล้วรันทุก Cell จะได้ไฟล์ `eye_state_cnn.h5` ในโฟลเดอร์เดียวกับ `main.py`

4. **รันระบบตรวจจับ**

   ```bash
   python main.py
   ```

   - ครั้งแรกโปรแกรมจะดาวน์โหลด `face_landmarker.task` อัตโนมัติ (ต้องต่ออินเทอร์เน็ต)
   - ลืมตาปกติมองกล้อง 3 วินาทีแรก เพื่อให้ระบบสอบเทียบเกณฑ์ของคุณ
   - ถ้าไม่พบ `eye_state_cnn.h5` ระบบจะใช้ EAR อย่างเดียวแทน

### การตั้งค่า

ปรับค่าได้ที่ส่วน Config ต้นไฟล์ `main.py` เช่น `CAMERA_INDEX` (เลือกกล้อง), `EYE_CLOSED_SOFT_SEC` / `EYE_CLOSED_LOUD_SEC` (เวลาเตือน), `YAWN_SEC`, `MAR_THRESHOLD` และ `ENABLE_YAWN_ALERT`

### ไฟล์ Log

แต่ละรอบการใช้งานจะสร้างไฟล์ `data-user/drowsiness_log_<วันที่_เวลา>.csv` มีคอลัมน์ `timestamp, event, level, duration_sec, detail` โดย event ได้แก่ `EYES_CLOSED_LONG`, `EYES_CLOSED_VERY_LONG`, `YAWN` และ `SESSION_SUMMARY` (สรุปจำนวนกะพริบ หาว และการเตือนเมื่อจบรอบ)
